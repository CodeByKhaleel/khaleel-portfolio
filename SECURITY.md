# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project,
please report it privately rather than publishing the
details in a public GitHub issue.

Please include:

- A description of the vulnerability.
- Steps to reproduce it.
- Any relevant screenshots or technical details.

I will review reported issues and take appropriate action.

Please do not include passwords, API keys, tokens,
or other sensitive information in public issues.
