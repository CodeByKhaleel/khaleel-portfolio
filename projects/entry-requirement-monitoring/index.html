Why it needs a workflow

Requirements do not live at one consistent level, and updates arrive in different forms.

Some entry requirements apply across a university. Others vary by nationality or by course. A monitoring workflow needs to find the relevant update and compare it with the current database record before an update is prepared.

Jira tickets are the checkpoint for updates. A scheduled bot checks tickets, follows the ticket to the related university email, and compares the email content with existing data. If an update is needed, the process creates an import file; if not, it marks the ticket done and moves on.
