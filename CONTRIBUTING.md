# Contributing Guidelines

Thank you for your interest in this project!

This repository contains the source code for my personal
portfolio website.

## Project Scope

This project is primarily maintained as a personal portfolio.
Contributions are not actively solicited.

## Reporting Issues

If you notice a bug or an issue with the website:

1. Check whether the issue has already been reported.
2. Open a GitHub issue with a clear description.
3. Include steps to reproduce the issue.
4. Add screenshots where helpful.

## Pull Requests

Please open an issue and discuss the proposed change
before submitting a pull request.

Pull requests may be reviewed at my discretion.

Thank you for respecting the purpose of this project.
