# Khaleel Portfolio

Static, responsive portfolio site for Mohammed Khaleelullah. The source uses semantic HTML, shared CSS design tokens, and a small JavaScript shell for navigation and mobile behavior.

## Preview locally

From this directory, run a static file server, for example:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173/`.

The site supports the GitHub Pages project path `/khaleel-portfolio/` and root-domain paths. Email and résumé actions are intentionally omitted until their exact details are supplied.

## Privacy

Raw source documents, certificate PDFs, résumé files, profile review notes, and design notes are excluded from Git. Only public portfolio copy and site code belong in this repository.
